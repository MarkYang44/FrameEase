FrameEase 0.1.1 improves desktop layout, adds a complete English interface, and updates the app artwork on macOS and Windows.

## Downloads

| Platform | Installer |
| --- | --- |
| macOS · Apple Silicon | `FrameEase_0.1.1_aarch64.dmg` |
| Windows 10/11 · x64 | `FrameEase_0.1.1_x64-setup.exe` (current user) |
| Windows 10/11 · x64 | `FrameEase_0.1.1_x64_en-US.msi` (per machine) |

FFmpeg is included. Check downloads against `SHA256SUMS.txt`. The macOS package minimum is set from the bundled FFmpeg; this release is built on macOS 15. Intel Mac packages are not available.

## Changes

- Replace the macOS, Windows, and Windows tile icons with the project-supplied artwork. Keep the original image and a repeatable icon-generation command.
- Prevent horizontal panning in the output settings panel; wrap long labels and values while keeping vertical scrolling and accessible menus.
- Keep Settings anchored at the bottom of the navigation when opening Info, changing pages, resizing, or showing notifications.
- Complete English text for every tool, dialog, tooltip, preset, compatibility notice, and time unit. Language changes also refresh mounted queue rows.
- Localize the generated name of imported presets without changing user-provided names.
- Rewrite the README with English and Simplified Chinese versions, current screenshots, and clear platform limits.
- Add translation and browser regressions to both platform CI builds. Preserve the Windows shared-FFmpeg packaging and installer integrity checks.

## Validation and limits

Local validation passed 165 Rust tests, 7 frontend tests, and 5 browser regressions, plus type checks, Clippy, and macOS packaging. Browser regressions use synthetic preview data; encoding tests use real FFmpeg with synthetic media. The release workflow tests and packages macOS and Windows, and checks both Windows installers before publication.

Windows physical desktop and NVIDIA/Intel/AMD hardware validation remain pending. HDR-to-SDR tone mapping is not implemented, and interrupted jobs restart from the beginning. Packages are not signed with a paid developer certificate; see [First launch](https://github.com/MarkYang44/FrameEase/blob/v0.1.1/README.md#first-launch).

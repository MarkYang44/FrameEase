FrameEase 的首个公开版本：本地视频压缩、转码与批量处理工具。安装包内置 FFmpeg 8.1，下载后即可使用。

## 下载

| 系统 | 文件 | 说明 |
| --- | --- | --- |
| Windows 10/11 x64 | `FrameEase_0.1.0_x64-setup.exe` | 推荐；安装到当前用户，无需管理员权限 |
| Windows 10/11 x64 | `FrameEase_0.1.0_x64_en-US.msi` | 按机器部署，需要管理员权限 |
| macOS 15+ · Apple Silicon | `FrameEase_0.1.0_aarch64.dmg` | 打开后把 FrameEase 拖进“应用程序” |

`SHA256SUMS.txt` 列出了每个文件的 SHA-256 校验和。暂不提供 Intel Mac 版本。

## 主要功能

- **有损压缩：** H.264、HEVC、AV1 相互转换；高画质 / 均衡 / 小体积 + 0–100 压缩程度，界面直接显示实际的 CRF / CQ / q:v；支持目标码率、目标体积与两遍编码。
- **无损重编码：** 只开放通过逐帧像素比对自检的“编码器 + 像素格式”组合，每个任务完成后再与原片逐帧比对；另有流复制与 FFV1 无损存档。
- **不偷换格式：** 默认保持分辨率与帧率；HDR、10-bit、4:4:4 不会被悄悄降级，不支持的组合直接拒绝并给出修正选项。
- **安全输出：** 原文件不动；先写临时文件、校验输出，再以“不覆盖”方式提交。坏文件、后端卡死或被占用的结果 CSV 都不会中断队列。
- **批量与工具：** 文件夹导入、拖放、每个任务独立的设置快照、暂停与重试、重启后恢复；试压（VMAF / SSIM / PSNR 与滑动对比）、截取、封装合并与轨道提取、媒体信息、预设。
- **硬件加速：** VideoToolbox、NVENC、Quick Sync、AMF，只有实测编码通过的编码器才会启用。

## 首次打开

安装包没有使用付费的开发者证书签名，系统会在首次打开时拦截：

- **macOS：** 双击打开一次，再前往“系统设置 → 隐私与安全性”，在页面底部点“仍要打开”。如果提示“已损坏”，在终端执行 `xattr -dr com.apple.quarantine /Applications/FrameEase.app`。
- **Windows：** 出现“Windows 已保护你的电脑”时，点“更多信息 → 仍要运行”。缺少 WebView2 运行时的系统会在安装时下载并安装它（需要联网）。

## 已知限制

- Windows 版尚未在实体电脑上验证：核心测试与打包在 GitHub Actions 的 Windows Server 2025 上通过；NVENC、Quick Sync、AMF 尚未在真实显卡上测试。
- macOS 版附带的 FFmpeg 不含 libass / libaom / rav1e：文字字幕烧录不可用（图形字幕可以），AV1 只能用 SVT-AV1。
- 被中断的任务会从头重新编码；快速截取的起点只能落在关键帧。
- 完整说明见 [README](https://github.com/MarkYang44/FrameEase/blob/v0.1.0/README.md#已知限制) 与[测试记录](https://github.com/MarkYang44/FrameEase/blob/v0.1.0/docs/TESTING.md)。

Download the Windows 10/11 x64 installer (`-setup.exe`, or the `.msi` for per-machine deployment) or the macOS 15+ Apple Silicon disk image (`.dmg`).

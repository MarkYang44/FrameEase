FrameEase 0.1.2 adds a Windows x64 no-install ZIP alongside the existing installers.

## Windows without installing FrameEase

1. Download `FrameEase_0.1.2_windows-x64-portable.zip`.
2. Extract the entire archive into a writable folder.
3. Double-click **FrameEase.exe**. Keep the `ffmpeg` folder beside the program.

FFmpeg, its DLLs, and license notices are included. No FrameEase installer or administrator rights are required. This package uses the **system WebView2 Runtime**; if your computer does not already have it, install the Evergreen Runtime from [Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/). Settings and queues continue to use the current user's application-data folder.

The release includes the macOS Apple Silicon DMG, Windows EXE/MSI installers, the no-install ZIP, and `SHA256SUMS.txt` covering all four packages.

## Validation

The Windows pipeline expands the ZIP into a folder with Unicode and spaces, compares every extracted file's SHA-256 with the staged source, runs FFmpeg/ffprobe without their directory on PATH, and launches the actual application from a different working directory. The startup check requires a native window and capability detection of the FFmpeg inside the extracted ZIP. The Windows application links the Visual C++ runtime statically.

Existing core, translation, browser, and installer checks remain part of release CI. Physical Windows 10/11 desktop acceptance and real NVIDIA/Intel/AMD hardware tests remain pending.
